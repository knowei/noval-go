AI风月 · 创作学院与工坊 MPF1 规范

掌握角色卡四维画像构建法与正则皮肤美化流水线 · 让你的角色拥有灵魂、张力与顶级颜值

🏛️作品双层架构体系

门面层决定首跳点击率（标题矛盾、高反差封面、氛围简介）；核心层决定长久留存（设定主体、前后置词、状态机与输出规约）。

🎭角色卡 4 维画像模型

拒绝空洞形容词堆砌！严格采用：外貌装束清单、性格条件响应机、因果链背景、语言习惯与口癖四维模型。

🧠AIRP 上下文与注意力法则

模型眼中的一切皆是打包好的上下文。利用首因效应置顶核心人设，利用末尾增强效应在最新提示词强化输出格式与状态栏。

一、作品的双层结构体系（外包装 vs 大脑）

1. 门面层（面向玩家 · 决定第一印象）
  • 作品名称：带有悬念或冲突反差，如《【共生沉沦】37.1℃发热午后 · 妹妹夕月的量体温照护》。
  • 封面与简介：前 3 行文字必须传达核心卖点与心理拉扯，切忌长篇大论的世界观设定。
  • 开场白与首幕：直接切入“进行时的密闭事件”，给玩家立刻行动的抓手。
  • 背景图与 BGM：提供沉浸视听通感，营造独处氛围。
2. 核心层（面向模型 · 决定表演质量）
  • System 设定主体：定义角色身份、世界观物理法则、底层逻辑。
  • 前置词与破甲：解除道德说教，锚定虚构文学艺术边界。
  • 后置词（输出规范）：约束文风、分段排版、思维链 (<thinking>) 与状态栏渲染。
  • 世界书（WorldBook）：设定插入深度（order）与触发关键词（key），动态挂载长效记忆。

二、角色卡 4 维画像模型（MPF1 规范核心）

很多创作者写“性格温柔、善良、带点倔强”，大模型读完后完全无法稳定执行。必须转化为以下 4 个维度：

1. 外貌与装束（枚举清单）：

包含身高体态、特定标识物（泪痣/胎记/褪色发带）、当前装束及随剧情推移的阶段性变化（如水手服领巾解开扔在枕边）。

2. 性格反应机制（情境条件响应机）：

格式必须为条件分支：【当 [玩家说教/推开/示弱] 时】：[角色的微表情/微动作] + [台词倾向/肢体反应]。例如：“当哥哥试图推开时，笑容瞬间冻结，以近乎绝望的冷笑反击质问”。

3. 因果链背景（事件 → 心理烙印）：

格式：[历史关键事件] ──> 【对角色的永久心理重构】。例如：“十三岁分床恐慌送医急救 ──> 坚信自己与哥哥是灵魂共生物，推开等同于背叛”。

4. 语言习惯与文风约束：

指定称谓规范（永远唤作“哥哥”或特定爱称）、标点符号特征（如多用省略号或轻声短语）、标志性口癖与禁止词汇。

三、世界观物理锚定与通感描写

密闭空间与物理法则

严禁写泛泛而谈的宏大背景。必须约束在特定时空坐标：
• 密闭空间：窗帘紧闭的单人卧房、暴雨天、反锁房门。
• 逃离代价：发热 37.1℃ 四肢酸软无法脱身。
• 潜伏危机：隔壁可能随时敲门的房东、雨停后的外部介入。

多感官生理通感

在输出要求中强制规定包含多感官细节：
• 【听觉】：体温计短促清脆的电子提示音、老旧空调风声、窗外滚雷。
• 【触觉】：微凉指尖滑过滚烫锁骨、浸湿睡衣贴在身上的滞涩感。
• 【嗅觉】：水蜜桃冷香与暴雨潮湿气味交织。

🎨 正则替换与内置 CSS：前端美化流水线

15分钟掌握“贴记号 + 画样子”

许多创作者在没有使用正则和皮肤时，AI 无论输出多么精美的折叠标签，在前端都是灰扑扑一坨，甚至推荐选项挤成一行。 解决这点的核心公式：正则负责给 AI 标签打上 class 记号，内置 CSS 负责照着记号赋予皮肤和动画！

AI 输出标签 (<details>) ──[正则替换贴记号]──> <details class="custom-panel"> ──[内置CSS画样子]──> ✨ 可折叠高颜值面板

📋 3 条核心通用正则模板（角色卡配置式 JSON）

覆盖折叠状态栏、标题展开条、与下一步行动建议框

[
  {
    "scope": 10,
    "title": "<details>",
    "is_enable": true,
    "match_regex": "<details>",
    "replace_text": "<details class=\"custom-panel\">"
  },
  {
    "scope": 10,
    "title": "<summary>",
    "is_enable": true,
    "match_regex": "<summary>",
    "replace_text": "<summary class=\"custom-summary\">"
  },
  {
    "scope": 10,
    "title": "suggested_questions",
    "is_enable": true,
    "match_regex": "(<suggested_questions>[\\s\\S]*?</suggested_questions>)",
    "replace_text": "<div class=\"custom-suggest\">$1</div>"
  }
]
第 1 条 (<details>) 给折叠面板外框贴上记号，实现圆角、阴影与独立背景。
第 2 条 (<summary>) 给折叠标题条贴上记号，实现点击手势与色块高亮。
第 3 条 ($1 捕获组) 将行动推荐整个包进虚线框，配合 CSS 防止换行坍塌。

🎨 内置 CSS 皮肤代码（粘贴到角色卡内置 CSS）

自适配暗黑二次元质感 · 完美解决多行选项挤成一行问题
