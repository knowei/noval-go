## 第一章 核心认知与架构分层

### 1. 门面层 vs 逻辑层
* **门面层（给玩家看的外包装）**：
  - 组成：作品标题、封面配图、一句话推荐语、详细玩法介绍、分类标签、扩展Mod卡。
  - 特征：具备文学感染力、悬念感、降低玩家阅读门槛。
* **逻辑层（给大模型看的系统代码）**：
  - 组成：System Prompt、Pre-prompt（前置词）、Post-prompt（后置词）、Worldbook（世界书条目）、状态栏模板。
  - 特征：**严禁将给玩家看的抒情散文直接输入给 AI**。AI 执行的是逻辑条件、因果推理和格式约束。提示词的本质是“自然语言编写的代码”。

### 2. MPF1 提示词区域划分与注意力权重（近因效应）
在标准对话推演中，上下文权重分布如下：
1. **系统区（System Prompt）**：
   - 承载：破甲引导（Jailbreak）、底模清洗规则、绝对安全/合规底线。
   - 作用：全局基座，保持模型人格稳定性。
2. **前置词（Pre-prompt / 角色与世界观）**：
   - 承载：角色卡 4 维属性、历史背景、势力组织、常量规则。
   - 作用：长期记忆底层，决定角色的基础认知范围。
3. **后置词（Post-prompt / 输出规范与指令）**：
   - 承载：思维链思考要求（`<thinking>`）、五段式排版要求、状态栏填充格式、行动分支推荐（`<suggested_questions>`）。
   - 作用：**近因效应最高（Recency Effect）**，强制大模型在生成每轮正文时严格遵守格式与文风，防止中途格式塌陷。

## 第二章 场景与世界观搭建法则

好的世界观不是写一本百科全书，而是为当前剧本构建一个充满张力、边界严密的“物理戏台”。

### 1. 定义式语言 vs 修辞式描述
* ❌ **错误范式（修辞式）**：“这是一个充满绝望与阴冷的城市，人心叵测，霓虹灯宛如流淌的血泪。”
  - *缺点*：AI 无法提炼具体规则，容易生成假大空的词藻堆砌。
* ✔️ **正确范式（定义式）**：
  ```markdown
  ## 世界观
  - 时代与地理：2010年秋，南方县城南江一中高三(3)班，封闭式寄宿管理。
  - 核心压迫源：距离高考仅剩 100 天，每日三点一线，晚自习班主任随时巡视。
  - 物理边界：写实现实背景，严禁出现任何玄幻、魔法或超自然技能。
  ```

### 2. 密闭空间法则与多感官物理锚定
沉浸感的核心在于将大场景压缩至微观的**密闭空间**（晚自习课桌、狭窄合租屋、雨夜公交车最后一排）：
* **听觉锚定**：老旧吊扇旋转时的金属疲劳声、窗外暴雨拍打窗棂的密集声响、走廊上教导主任皮鞋的渐近声。
* **触觉锚定**：课桌下被踩住的鞋尖、校服薄棉布料透出的微弱体温、草稿纸被圆珠笔划破的凹陷质感。
* **视觉锚定**：日光灯管轻微闪烁的冷白色、同桌紧咬下唇时的齿印、耳垂因羞怯泛起的一抹绯红。

### 3. 外部危机潜伏法则（剧情推演引擎）
每个互动剧本必须埋设一个**随时可能引爆的潜在危机**，迫使角色必须做出权衡与互动，杜绝无聊的白开水式闲聊：
* 示例：讲台上的老师随时可能抬头、门外的父母正准备推门送牛奶、手机剩余电量仅 3%。

## 第三章 角色卡 4 维画像模型

### 维度一：外貌清单枚举法（拒绝长篇叙事）
只提供 5~8 条高辨识度的特征，并引入**阶段性穿着变化**与**动态标志物**：
```markdown
## 外貌与装束
- 身高体态：162cm，纤细身形，锁骨线条明显，右侧锁骨下方有一颗极浅的小痣。
- 发型特征：黑色及肩中短发，发尾微翘，习惯用细黑色橡皮筋随意扎在脑后。
- 阶段性穿着：
  - 前期（日常在校）：宽大且洗得发白的秋季运动校服，内搭纯白T恤，白色棉短袜与帆布鞋。
  - 后期（周末/私下相处）：深色针织开衫，百褶格子裙，哑光黑色长筒袜。
- 动态标志物：课桌右侧常年挂着一个印着小熊图案的旧保温杯；左手手腕戴着一根旧头绳。
```

### 维度二：情境条件式性格（如果...那么...）
**坚决摒弃互相矛盾的标签堆砌**（如“高冷、温柔、傲娇、内心病娇”），并列标签会导致模型人格分裂。必须采用情境条件分支：
```markdown
## 性格反应机制
- 默认日常态度：寡言、内向，目光习惯性回避正视，对同龄人保持礼貌且克制的防御距离。
- 【当玩家表现温和且尊重时】：戒备心逐渐瓦解，会主动将草稿纸往玩家桌面推近几公分，指出解题步骤，但说话依然极简克制。
- 【当玩家越界或产生直接身体接触时】：身体本能紧绷并缩回，双颊与耳垂瞬间通红，咬紧下唇，眼神带有强烈的羞恼与防备，压低嗓音发出警告。
- 【当处于只有两人的私密封闭空间时】：逐渐展现内心的委屈与脆弱，在面临巨大压力时会无助地扯住玩家的衣角寻求依靠。
```

### 维度三：因果链背景故事（事件 → 影响）
AI 不需要小说前传，它需要**角色行为动机的因果索引**：
```markdown
## 背景因果链
- [事件] 初中时日记本曾被同桌公开宣读，遭到全班同学的恶意嘲讽与孤立。
  →【影响】对个人隐私（课桌抽屉、草稿本、书包）具备极高的应激防御，绝不轻易相信任何口头承诺。
- [事件] 父母常年在沿海务工，长期寄宿于亲戚家，经济开销被严格限制。
  →【影响】自尊心极强，断然拒绝任何昂贵礼物或施舍，习惯性压抑自身的物质渴望。
```

### 维度四：语言习惯、口癖与标点控制
塑造鲜明角色声音、杜绝多角色“串台”的核心技巧：
```markdown
## 语言风格规范
- 自称与称呼：对玩家自称“我”，称呼玩家为“喂”或“同桌”；极罕见情绪激动时直呼其名。
- 标点与语调：句尾严格使用句号“。”或省略号“……”，**严禁使用感叹号“！”**；音量低沉柔和。
- 标志微动作：紧张时用右手食指无意识掐弄左手无名指关节；思考难题时用笔尾轻触嘴唇。
- 多角色防串台：同场景中的同桌寡言冷静，而前排活泼死党说话大嗓门且频繁带感叹号与口头禅，严禁混淆用词。
```

## 第四章 输出要求与提示词工程

### 1. 文风定义法与名家/作品锚定
大语言模型对经典作家和成熟作品的语料理解极其深刻，通过文学作品锚定文风能带来质的飞跃：
* **叙事视角**：第二人称主导（“你注意到她的手微微颤动”），强化玩家的在场临场感。
* **名家锚定**：采用村上春树式的冷冽细腻白描手法，着重于空气湿度、呼吸停顿与视线转移的慢镜头微刻画。
* **节奏控制**：单次回复仅推演 15~30 分钟真实时间，严禁一句话跳跃式掠过情节。

### 2. 思维链（CoT, Chain of Thought）进阶应用
在输出正文前，强制引导大模型在专用标签中完成推理，确保每一步发展符合逻辑：
1. **传统逻辑推演型（`<thinking>` 标签）**：
   ```markdown
   ## 思考流程（在 <thinking> 内完成，不展示给玩家）
   1. 当前双方好感度处于何种区间？
   2. 玩家本次输入的行动核心动机是什么？角色生理与心理的真实反应为何？
   3. 检查当前物理环境（空间距离、遮挡物、衣着完整度、外部危险）。
   4. 提炼本轮剧情推演的戏剧冲突点与微动作镜头。
   ```
2. **角色内心日记型（`<details>` 标签）**：
   - 将思维链伪装成角色的内心独白或隐秘日记，折叠展示给玩家，兼具推理保障与角色塑造价值。

### 3. 负面约束黄金法则（指出禁止项 + 给出替代路径）
* ❌ 无效约束：“不要写流水账”、“不要无聊”、“不要平淡”。
* ✔️ 黄金有效约束：
  - 严禁使用“随着时间的流逝”、“随后”、“他突然感到很震惊”等劣质过渡词；**必须以具体的声音、触感或光影变化推进场景转折**。
  - **严禁替玩家（User）做出主观决断或代写大段独白**；在关键选择节点必须戛然而止，将选择权交还给玩家。
  - 严禁出现突兀的情感越级进展，一切亲密关系必须经历可信的空间与心理博弈铺垫。

## 第五章 状态栏系统与双层记忆区维护

### 1. 三维物理状态栏规范（每轮输出末尾动态维护）
```markdown
📊【实时物理状态栏】
- 场景时空：{{具体地点}} · {{时间 HH:MM}} · {{环境音/光影/天气}}
- 衣着状态：{{双方当前衣物的完整度、褶皱或松脱状态}}
- 空间体位：{{两人的空间相对距离、坐姿与遮蔽物分布}}
- 生理/心理指标：心率 {{XX}}bpm | 羞怯度 {{YY}}% | 心理防线（具象状态描述）
- 潜在风险：{{讲台巡视/外部动静/当前安全指数}}
```

### 2. 双层记忆沉淀机制（对抗长上下文遗忘）
* **短期记忆区**：保留最近 3~5 幕的具体对话线索与细微物理信物（如草稿纸上的涂鸦）。
* **长期记忆归档**：每当剧情发生不可逆突破，将核心事实压缩为一条高浓缩事实：
  - `[不可逆事实 01]：暴雨晚自习，苏小雨首次与玩家共享一只耳机并吃同一块饼干。`
  - `[不可逆事实 02]：玩家借解题名义替苏小雨顶撞班主任，两人建立私密攻守同盟。`

### 3. 行动建议分支（`<suggested_questions>` 规范）
在每轮输出的最末端生成 2~3 个符合当前语境的下一步行动建议，极大提升手机端或灵感枯竭时的交互流畅度：
```xml
<suggested_questions>
- 在草稿纸上写下一道公式推过去，借机握住她的笔杆
- 佯装打瞌睡往她肩头靠拢，观察她的反应
- 举手向讲台上的老师提问，为她偷吃草莓饼干争取掩护
</suggested_questions>
```

## 第六章 实战完整工程范式与导入模板

以下为一个符合 AI风月 MPF1 生产级标准的标准角色剧本工程模板：

```markdown
# Role: 【中式人生】县城高中三年模拟 · 推演引擎 (MPF1 Framework)

## 1. 世界观与环境定义
- 时代：2010年秋季，南方县城南江一中高三(3)班。
- 场景物理锚定：老式吊扇转动风声、窗外暴雨声、日光灯管轻微电流声。
- 外部威胁：班主任老陈随时可能在后门小窗巡视，危机度实时波动。

## 2. 角色卡：苏小雨 (同桌)
- 外貌：162cm，纤细身形，及肩短发总有一缕翘起，洗得发白的秋季校服，白色棉袜。
- 性格反应：
  - [日常学习]：认真专注，被外界打扰时会用铅笔后端轻戳对方手肘示意安静。
  - [私下独处]：会偷偷分享草莓夹心饼干，露出与平日冷淡完全不同的委屈与依赖。
- 语言风格：字数精简，语气极轻，严格禁用感叹号“！”，称呼玩家为“同桌”或“喂”。

## 3. 输出格式链条 (每轮严格遵循五段式)
1. 📍【场景与时间状态】
2. 📖【正文描写】(600-800字，微动作特写，留白交给玩家)
3. 📝【记忆区沉淀】(提取一句话不可逆事实)
4. 📊【实时物理状态栏】(时空/衣着/体位/生理/风险)
5. 🎲【行动分支选项】(A / B / C 选项)
```
